# Screenshot checklist

The guide uses screenshot **placeholders** (callout boxes), so the site builds without any images. To add a real screenshot:

1. Take it from the int environment (https://rakkii-ops-int.web.app) using demo data. **Never include real customer names, plates, phone numbers or peso amounts.**
2. Save it as PNG at the exact path below, under `docs/public/screenshots/` (create the chapter folder if needed).
3. In the chapter, replace the placeholder callout with `![Description](/screenshots/<chapter>/<file>.png)`.
4. Tick the box here.

Recommended width: 1280–1600 px desktop, 390 px for phone screens (clock-in, My jobs, QC photos).
