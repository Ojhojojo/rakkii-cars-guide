## User Guide

Short, task-based guides for owners and the desk, technicians and sales agents: one job from booking to release in 8 steps, insurance and corporate jobs, fixing mistakes, running the shop, and the Me hub. Detailed rules are in the Reference section.

- Guide: https://ojhojojo.github.io/rakkii-cars-guide/
- Guide repository: https://github.com/Ojhojojo/rakkii-cars-guide
- Run it locally: `npm install && npm run docs:dev` in that repository

When a change in this repo renames a page, tab, button, field, status or release check, update the matching page in the guide.
